# FocusFeed 0.2.1：文件夹刷新、大屏布局与安卓热更新修复

发布日期：2026-10-11（香港时间）

[官网原文](https://darastas.github.io/announcements/release-0-2-1.html)

> 文件夹可单独刷新；折叠屏和平板新增显示方案与栏宽调整。Android 0.2.1 APK 修复热更新不可用的问题，整包检查更新按平台分别提供。

**0.2.1 带来文件夹刷新、大屏显示方案与栏宽调整。** Windows 和 Linux 的 0.2.0 用户可通过签名界面小更新获取这些功能；Android 用户请先覆盖安装 **0.2.1 APK**，修复 0.2.0 中热更新不可用的问题。订阅、文章、笔记和许可继续保存在本机。

## Android：修复热更新不可用

Android 0.2.0 的更新模块使用了不受该平台支持的标准库文件锁，并把初始化失败误报为「另一个窗口正在管理更新 / Another instance is managing updates」。因此即使只有一个应用进程，也无法检查、下载或导入界面小更新。

0.2.1 APK 改用 Android 支持的系统文件锁，并分别报告锁占用与实际初始化错误。此修复属于原生核心，须[下载 Android 0.2.1 APK](https://darastas.github.io/#download)后覆盖安装；请保留原应用和数据，直接安装新版。新版 APK 已包含下述界面功能，后续仍可使用签名界面小更新。

整包检查更新按 Windows、Android、Linux 分别读取对应清单。旧 Windows 客户端继续使用 0.2.0 的共同版本清单，不会因本次仅发布新版 APK 而提示桌面整包升级；Android 0.2.0 用户需要从官网手动安装本次修复版。

## 单独刷新文件夹

- 打开文件夹的菜单，选择「刷新文件夹」，只刷新这个文件夹中的本地阅读源；其他文件夹和电子书不会随之刷新。
- 刷新时显示进度状态。空文件夹会提示没有可刷新的源，部分失败时会显示失败数量。
- FreshRSS、Miniflux 等远程服务沿用账户同步接口，菜单明确显示「同步所属账户」：会同步整个所属账户，同一账户只调用一次。

## 折叠屏和平板：选择自己的显示方式

展开折叠屏或使用平板时，进入「设置 → 显示布局」。应用根据移动设备的屏幕尺寸和比例显示这一页；普通手机和桌面端继续使用原有设置。

- **单页显示**：展开后也像手机一样，一次显示一栏，按订阅源、文章列表、阅读页逐层进入和返回。
- **自动分栏**：保留原有方案，根据可用空间显示两栏或三栏。常见折叠屏展开后为两栏；三折叠、阔折叠和平板在空间足够时显示三栏。
- 两种方案使用静态灰卡片示意，便于理解布局。显示方案会保存在本机，旋转或重新打开应用后继续使用。

这里依据可用屏幕空间判断布局，不依赖具体机型或铰链识别；界面缩放也会影响自动分栏结果。

## 栏宽可以调整

- 同一设置页提供「三栏宽度」预览：直接拖动灰卡片之间的两条分界线，查看订阅源、列表、阅读区的比例，也可恢复默认。
- 移动端主界面支持**长按栏分界线，再左右拖动**。两栏默认居中，三栏使用设置中的比例，调整结果会记住。
- 短触不会立即改变栏宽。桌面端仍可直接拖动分界线。
- 调整后的二栏布局支持文章切换、返回和专注阅读；切换显示方案或旋转时保留正在阅读的文章。

## 如何更新与恢复

Windows/Linux 0.2.0 用户进入「设置 → 关于 → 界面小更新」，主动检查并下载 0.2.1。也可以[下载签名更新包](https://focusfeed-site.pages.dev/download/ui/FocusFeed_0.2.1.ffupdate)，通过「导入更新包」安装。Android 0.2.1 修复版中也可使用此入口获取后续界面更新。

- 更新包在本地验签后，下次启动生效。Windows 和 Linux 可点击「重启并应用」；Android 请结束应用后重新打开。
- 尚未应用时可以「取消待更新包」；应用后可以「恢复上一界面」，再重新打开应用。
- 新界面启动失败时，核心会自动恢复上一可用界面或内置界面。恢复界面不会删除订阅、文章和许可。
- 取消或恢复后，同一更新序号不能再次应用；要再次更新，请等待开发者提供更高序号的包。
- 开发者也可发布更高更新序号的旧界面资源来撤回本次变更。下架更新包不会使已安装或离线设备自动回退。

文件夹刷新与大屏布局使用 0.2.0 已有的本地接口，没有新增数据库迁移、系统权限或登录系统。更新检查和下载不向更新服务上传订阅、文章、授权码或 API 密钥。安装包下载区提供 **Windows/Linux 0.2.0** 与 **Android 0.2.1**；使用更早版本的用户请先[安装对应平台版本](https://darastas.github.io/#download)，再使用界面小更新。

界面更新可以取消、回退和由开发者撤回；Android 文件锁修复和平台检查逻辑属于原生代码，界面回退不会撤销这些修复。Android 实机操作由用户验收，本次没有把浏览器或 Windows 验证作为手机实测结果。
