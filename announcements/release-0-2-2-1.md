# FocusFeed 0.2.2.1：可选启动预加载与外链打开修复

发布日期：2026-10-12（香港时间）

[官网原文](https://darastas.github.io/announcements/release-0-2-2-1.html)

> 设置中新增默认关闭的启动预加载，支持最近 20、30 篇未读文章与自定义数量，并提醒流量消耗；正文外链通过系统浏览器打开。新版安装包包含媒体卡片和此前的全文修复。

**FocusFeed 0.2.2.1 增加可选的启动预加载，并修复正文外链无法访问的问题。** 同时包含 0.2.2 的完整正文、YouTube 卡片、播客播放器和定时同步功能。Windows、Android 与 Linux 均提供本次安装包，官方公告 RSS 同步更新。

## 启动预加载：先准备几篇未读文章

进入**设置 → 通用 → 启动预加载**，勾选「每次打开软件，预加载最近的未读文章」，选择篇数后点击「应用」。这一功能**默认关闭**，由你决定是否启用。

- 可以选择最近 **20 篇**、**30 篇**，或自定义 **1–1000 篇**。
- 每次打开软件时，按文章发布时间选择最近的未读文章，在后台缓存正文；不受列表置顶顺序影响。
- 保留未读状态，不改变收藏和批注；已有全文缓存会跳过，不重复下载。
- 官方公告与电子书章节不参与预加载。图片和音视频仍在阅读或播放时按需加载，不会自动下载播客或视频文件。
- 暂时离线或网站失败时保留源内摘要，下次启动仍可重试。关闭选项并应用后，停止后续文章的预加载。

**预加载会访问文章原网页，可能消耗较多流量。** 设置旁会持续显示流量提醒，建议在 Wi-Fi 下开启，或减少篇数。该功能仅在软件启动后运行，关闭软件后不会继续后台下载；它是每次启动的数量设置，没有每月下载配额。

启动预加载需要 **0.2.2.1 安装包中的原生核心**。旧版通过界面小更新可看到设置说明，安装新版后才能开启。

## 正文外链通过系统浏览器打开

之前正文链接使用应用内 iframe 查看，一些网站会拒绝嵌入，导致点击链接后无法访问。本次将普通正文外链交给系统浏览器打开，继续保留「打开外部链接前确认」的设置。

YouTube 继续使用正文中的视频卡片：点击播放后才连接 YouTube 的隐私增强嵌入播放器，点击前不请求视频或缩略图。卡片上的外部观看按钮也可打开系统浏览器。

新版安装包已包含媒体界面。覆盖安装时，较旧的界面小更新不会遮住新版内置功能；仍保留阅读数据、许可和更新序号。

## 同时包含 0.2.2 的更新

- 修复 4Gamers 部分文章只显示标题、封面或开头，以及部分正文中的 YouTube 视频被遗漏的问题。
- 旧 4Gamers 全文缓存会在下次全文阅读时重新尝试抓取，保留阅读记录、收藏和批注。
- 播客及音视频控件支持播放暂停、进度、快退 15 秒、快进 30 秒、倍速、音量和视频全屏；全文后保留 RSS / Atom 媒体附件。
- 设置 → 通用提供 15 分钟、30 分钟、1 小时及自定义时间的定时同步。应用运行时生效，设备休眠或离线可能延后。
- 文件夹支持单独刷新、一键调整文章解析方式，并默认收起；折叠屏和平板可选择显示方案和调整栏宽。

FreshRSS、Miniflux 等服务仍按所属账户同步。新核心可统一调整本地 RSS 与远程账户的同步间隔；旧核心只调整本地 RSS。电子书和系统公告源不参与此间隔设置。

请保留原应用与数据，安装对应平台新版。Android 可以直接覆盖安装，签名延续此前版本。应用检查更新按平台分别提供安装包。

- [Windows 0.2.2.1 安装版](https://focusfeed-site.pages.dev/download/FocusFeed_0.2.2.1_x64-setup.exe)

- [Android 0.2.2.1 ARM64 APK](https://focusfeed-site.pages.dev/download/FocusFeed_v0.2.2.1_arm64.apk)
- [Linux 0.2.2.1 x86_64 DEB](https://focusfeed-site.pages.dev/download/FocusFeed_0.2.2.1_amd64.deb)

Linux 继续标为 Beta，需 WebKitGTK 4.1 与 glibc 2.34 或更新版本。[官网下载区](https://darastas.github.io/#download)提供校验值和终端安装方式。

## 界面小更新与回退

媒体控件、外链打开修复和设置页面也通过**设置 → 关于 → 界面小更新**下发，本次更新序号为 **9**。也可[下载签名界面包](https://focusfeed-site.pages.dev/download/ui/FocusFeed_0.2.2.1-ui.1.ffupdate)，通过「导入更新包」安装。

- 界面包兼容 0.2.0 至 0.2.2.1 核心；Android 0.2.0 请先通过新版 APK 修复热更新模块。
- 下载后下次启动生效。Windows 和 Linux 可「重启并应用」；Android 请结束应用后重新打开。
- 尚未应用时可以取消待更新；应用后可恢复上一可用界面，再重新打开应用。新版核心会使用与其版本相适应的界面。
- 界面回退保留订阅、文章、许可、同步间隔和预加载设置；需要停止预加载时，请在设置中关闭。
- 启动预加载、全文提取、旧缓存修复及 RSS 附件解析属于原生能力，界面回退不会撤销这些核心功能。

订阅、文章、设置和许可继续保存在本机，没有新增登录系统或云端阅读数据库。更新检查与下载不上传订阅、文章、授权码或 API 密钥；启用预加载后，软件按你的设置访问相应文章网站。
