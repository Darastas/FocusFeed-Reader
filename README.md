# FocusFeed 阅读器

把注意力还给阅读。FocusFeed 是一款本地优先的 RSS 阅读器，提供 Windows 和 Android 版本，支持文章阅读、电子书、高光批注，以及使用自己的 AI 接口进行摘要、翻译和解读。

**官网与界面演示：** [darastas.github.io](https://darastas.github.io/)
